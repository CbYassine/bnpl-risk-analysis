# bnpl-risk-analysis
This is a display of some of my SQL skills, took a mock data from kaggle, which represents a sort of financial data, the data was processed through Google Big Query, then visualized by Google Data Studio (Looker Studio)

Project Overview
This project analyzes Buy Now Pay Later (BNPL) customer data to explore financial risk, customer debt, income, credit scores, and borrowing behavior.
The project follows a simple structure Raw data then Production then Dashboard workflow. Raw BNPL data is transformed and queried in Google BigQuery using SQL, then connected to Google Looker Studio/Data Studio to create an interactive risk analysis dashboard.
The objective is to transform raw customer-level data into meaningful financial risk indicators and provide a clear view of how BNPL debt varies across different customer segments.
Key Skills Used :

  Google BigQuery
  Looker Studio
  Google Cloud
  Data transformation
  SQL window functions
